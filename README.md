🎯 เกี่ยวกับโปรเจกต์
 
Cache-Simulator เป็นโปรเจกต์เพื่อการศึกษาที่ช่วยให้คุณเข้าใจพฤติกรรมของระบบแคช โดยจำลองการทำงานของแคชด้วยกลยุทธ์ต่างๆ และแสดงผลสถิติที่เข้าใจง่าย เหมาะสำหรับนักศึกษา นักพัฒนา และผู้ที่ต้องการเรียนรู้หลักการทำงานของแคช
 
💡 เดิมทีพัฒนาโดย Fabian Schwarzfritz — นำมาเก็บรักษาและปรับปรุงเพื่อวัตถุประสงค์การเรียนรู้ครับ

🚀 การติดตั้งและใช้งาน
 
ข้อกำหนดเบื้องต้น
 
- ☕ Java JDK 8 หรือเวอร์ชันที่ใหม่กว่า
- 🛠️ Apache Maven (หรือใช้คำสั่งคอมไพล์ตรง)
 
วิธีที่ 1: คอมไพล์ด้วยคำสั่ง
 
bash  
# โคลนโปรเจกต์
git clone https://github.com/zyntromedia/Cache-Simulator.git
cd Cache-Simulator

# คอมไพล์โค้ดหลัก
javac -d bin src/org/iteabag/simulator/**/*.java

# คอมไพล์และรันตัวอย่าง
java -cp bin org.iteabag.simulator.YourMainClass
 
 
วิธีที่ 2: ใช้ใน IDE
 
1. เปิดโปรเจกต์ด้วย IntelliJ IDEA, Eclipse หรือ VS Code
2. ตั้งค่าโฟลเดอร์  src/  เป็น Source Root
3. ตั้งค่าโฟลเดอร์  test/  เป็น Test Source Root
4. คอมไพล์และรันได้ทันที
 
 
 
🧠 กลยุทธ์แคชที่รองรับ
 
กลยุทธ์ คำอธิบาย 
NoCache ไม่ใช้แคชเลย — ทุกครั้งต้องอ่านจากแหล่งที่มา 
FIFO First-In-First-Out — ขจัดรายการที่เก่าสุดออกก่อน 
LIFO Last-In-First-Out — ขจัดรายการล่าสุดที่เพิ่งเข้ามาออกก่อน 
LRU Least Recently Used — ขจัดรายการที่ไม่ได้ใช้นานที่สุดออกก่อน 
MRU Most Recently Used — ขจัดรายการที่เพิ่งใช้ล่าสุดออกก่อน 
LFU Least Frequently Used — ขจัดรายการที่ถูกเรียกใช้น้อยที่สุดออกก่อน
